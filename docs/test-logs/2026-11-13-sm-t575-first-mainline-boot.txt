======================================================================
1. EXECUTIVE SUMMARY
======================================================================

CONFIRMED: SM-T575 successfully booted an experimental mainline
Linux 7.3.0 kernel and diagnostic initramfs from its BOOT partition.

The diagnostic console appeared on the tablet's own display. The Mac
enumerated a USB NCM network device; a TCP/23 connection over IPv6
succeeded and /proc/version was read directly from running Linux.

Further read-only diagnostics confirmed:
  - Correct LTE board model in the live device tree.
  - 3,761,204 kB of usable RAM (~3.59 GiB).
  - UFS block devices sda, sdb, sdc, sdd, sde, with partition nodes.
  - Battery capacity, voltage, charging state and temperature values.
  - Exynos DRM framebuffer and an active 1200x1920 DSI connector.
  - GPIO-keys input device.
  - Present Himax and Wacom kernel module files, but neither was loaded
    and neither appeared as an input device.
  - I2C clients enumerated; SPI bus had no visible devices at test time.

This was a diagnostic BOOT-only experiment, NOT a complete Linux
distribution or postmarketOS installation. There has been no successful
touchscreen, S Pen, Wi-Fi, Bluetooth, modem, audio, safe suspend,
graphical compositor or filesystem-mount test yet.
